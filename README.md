## 📖 Overview
<a id="overview"></a>

**IPConfig** is a user-friendly graphical interface for the MS-DOS command of the same name, designed to simplify the process of finding your computer's IP information. This powerful tool allows you to access essential data such as internal and external IP addresses, MAC addresses, network adapter names, and more, all in an easy-to-navigate format. 

With **IPConfig**, you can easily view your DNS server's IP address, subnet mask, and gateway IP, making it an indispensable tool for anyone needing quick access to their network information. Don't hesitate - download the latest version today for complete functionality!
